# PRIME SERVIÇOS

Site React baseado no projeto enviado anteriormente pelo cliente, adaptado para serviços elétricos, manutenção e montagem de computadores.

## Conteúdo desta versão
- Elétrica residencial
- Elétrica industrial
- Montagem e manutenção de computadores
- Galeria com 5 fotos de computadores enviadas nesta conversa
- Animações de entrada durante a rolagem
- Barra de progresso da página
- Efeitos de hover e elementos flutuantes
- Botão de WhatsApp com mensagem automática
- Layout responsivo

## Imagens
As fotos de computadores estão em `public/images/computadores/`.
As pastas `residencial/` e `industrial/` estão preparadas para receber as fotos correspondentes.

O arquivo `public/logo-prime.svg` é uma identidade provisória em SVG. Substitua-o pela logo oficial quando ela for enviada.
